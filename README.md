# Abartılı Tembel Hesap Makinesi

## Bilimsel Açıklama

Bu proje, insanlığın en büyük sorunlarından biri olan "hesap yapmak istememe" fenomenini çözmek için tasarlanmıştır. Yapay zeka çağında bile insanlar hala 2+2'yi hesaplamaktan kaçınmaktadır. Bu makine, o tembelliği bilimsel olarak modellemektedir.

### Özellikler
- Gerçekten hesap yapar (istemese de).
- Her hesapta 2-5 saniye bekler çünkü yorulur.
- Sonucu söyler ama "bunu yapmak istemedim" der.
- Hata durumunda uyur.

### Kullanım
```bash
python tembel_hesap.py
```

Bu proje tamamen ciddi bir araştırmadır. Lütfen şaka sanmayın. (Aslında şakadır ama ciddiye alın.)
